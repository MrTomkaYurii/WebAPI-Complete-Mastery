# 02. Web API Core, Minimal APIs & Scalar UI

> Сучасна розробка API на .NET 10: маршрутизація Minimal APIs, інтеграція сучасної документації Scalar UI (заміна Swagger UI) та надійна робота з конфігурацією через Options Pattern.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 02-WebAPI-Core-MinimalApis-And-Scalar

# Збірка проектів модуля
dotnet build
```
