# 03. Validation, Middleware & Global Error Handling

> Комплексна валідація вхідних даних (FluentValidation), обробка ModelState, пайплайн поведінки MediatR (IPipelineBehavior) та централізований перехоплювач винятків (Global Exception Middleware / ProblemDetails).

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead
