# 04. Data Mapping (AutoMapper) & Seeding (Bogus)

> Мапінг сутностей у DTO за допомогою AutoMapper (профілі, проекції), генерація реалістичних тестових наборів даних через Bogus та сценарії автоматизованого збору даних (Scraping).

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 04-Data-Mapping-And-Seeding

# Збірка проектів модуля
dotnet build
```
