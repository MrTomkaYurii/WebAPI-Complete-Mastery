# 05. Advanced Querying: Paging, HATEOAS, Specification & Expressions

> Побудова REST API промислового рівня: пагінація, фільтрація, сортування, формування форми даних (Data Shaping), підтримка HATEOAS, патерн Specification та динамічні Expression Trees.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead
