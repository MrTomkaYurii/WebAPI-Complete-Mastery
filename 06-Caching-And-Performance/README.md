# 06. Caching & High Performance (InMemory & Redis)

> Оптимізація швидкодії веб-сервісів: кешування в пам'яті (`IMemoryCache`), розподілене кешування в Redis (`IDistributedCache`), інвалідація кешу та зниження навантаження на БД.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.
