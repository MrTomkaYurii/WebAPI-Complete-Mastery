# 07. Structured Logging & Observability (Serilog & OpenTelemetry)

> Повний моніторинг enterprise-додатків: структуроване логування із Serilog (консоль, файли, sink), розподілене трасування, метрики та експорт через OpenTelemetry до панелі моніторингу.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 07-Logging-And-Observability

# Збірка проектів модуля
dotnet build
```
