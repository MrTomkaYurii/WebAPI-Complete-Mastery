
| Рівень          | Пояснення українською                                                            |
| --------------- | -------------------------------------------------------------------------------- |
| **Verbose**     | Найдокладніший рівень логування, рідко використовується у продакшн-додатках.     |
| **Debug**       | Для внутрішніх подій системи, що допомагають зрозуміти, як щось відбулося.       |
| **Information** | Події, що описують нормальну роботу системи відповідно до її функцій та завдань. |
| **Warning**     | Попередження про відхилення від норми чи ризик зниження якості сервісу.          |
| **Error**       | Помилки, коли функціонал недоступний або очікувана поведінка порушена.           |
| **Fatal**       | Найбільш критичні події, що вимагають негайного втручання.                       |
