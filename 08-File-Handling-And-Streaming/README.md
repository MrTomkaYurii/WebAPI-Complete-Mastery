# 08. File Handling, Multipart Upload & Streaming

> Завантаження та обробка файлів: просте завантаження через IFormFile, інтеграція файлів у Swagger UI, оптимізоване потокове завантаження великих файлів без переповнення пам'яті та збереження файлів у БД.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 08-File-Handling-And-Streaming

# Збірка проектів модуля
dotnet build
```
