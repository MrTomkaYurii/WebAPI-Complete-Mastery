# 09. NoSQL & MongoDB Integration

> Глибока інтеграція NoSQL документоорієнтованої бази даних MongoDB з ASP.NET Core: CRUD-операції, типізовані колекції, складні агрегаційні пайплайни ($lookup, $match, $group) та транзакції.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 09-NoSQL-MongoDB-Integration

# Збірка проектів модуля
dotnet build
```
