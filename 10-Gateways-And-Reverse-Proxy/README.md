# 10. API Gateways & Reverse Proxy (YARP & Ocelot)

> Організація єдиної точки входу для мікросервісів: сучасний високонавантажений зворотний проксі-сервер Microsoft YARP (Yet Another Reverse Proxy) та Ocelot API Gateway з підтримкою gRPC.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 10-Gateways-And-Reverse-Proxy

# Збірка проектів модуля
dotnet build
```
