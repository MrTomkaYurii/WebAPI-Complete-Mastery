# 11. Unit & Integration Testing in ASP.NET Core

> Автоматизоване тестування веб-сервісів: модульні тести на xUnit, створення моків сервісів і репозиторіїв через Moq, та повноцінні інтеграційні тести API за допомогою WebApplicationFactory.

## 🛠️ Стек технологій
- **Платформа:** .NET 10 (net10.0)
- **Архітектура:** ASP.NET Core Web API / Clean Principles
- **Цільова аудиторія:** Розробники рівня Junior / Middle / Tech Lead

---

## 📂 Структура модуля

У цьому модулі містяться готові зразкові проекти, адаптовані під .NET 10, які можна запустити самостійно.

## 🚀 Швидкий старт

```bash
# Перехід у папку модуля
cd 11-Unit-And-Integration-Testing

# Збірка проектів модуля
dotnet build
```
